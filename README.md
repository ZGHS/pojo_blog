# POJO 的博客

一个基于 Hexo 和 Fluid 主题构建的个人技术博客。

## 📚 项目简介

这是一个使用 Hexo 静态博客生成器和 Fluid 主题创建的个人博客网站，包含技术分享、生活感悟等内容。

## 🛠 技术栈

- **框架**: Hexo 5.4.2
- **主题**: Fluid 1.9.8
- **前端框架**: Bootstrap 4.5.3
- **图标库**: Iconfont (阿里巴巴矢量图标库)
- **代码高亮**: Highlight.js
- **搜索功能**: 本地搜索

## 📁 项目结构

```
pojo_blog/
├── 2021/           # 2021年文章归档
├── 2025/           # 2025年文章归档
├── about/          # 关于页面
├── archives/       # 归档页面
├── categories/     # 分类页面
├── css/            # 样式文件
├── img/            # 图片资源
├── js/             # JavaScript 文件
├── links/          # 友链页面
├── tags/           # 标签页面
├── video/          # 视频资源
├── xml/            # XML 文件
├── 404.html        # 404页面
├── LICENSE         # 许可证文件
├── atom.xml        # Atom 订阅
├── index.html      # 首页
└── local-search.xml # 本地搜索索引
```

## ✨ 功能特性

- ✅ **响应式设计**: 支持桌面端和移动端访问
- ✅ **暗黑模式**: 一键切换明暗主题
- ✅ **代码高亮**: 支持多种编程语言语法高亮
- ✅ **本地搜索**: 快速搜索博客内容
- ✅ **图片懒加载**: 优化页面加载速度
- ✅ **平滑滚动**: 流畅的页面滚动体验
- ✅ **文章分类**: 按分类和标签组织内容
- ✅ **文章归档**: 按时间线浏览历史文章

## 🚀 快速开始

### 安装依赖

```bash
npm install hexo-cli -g
npm install
```

### 开发模式

```bash
hexo server
```

### 构建生产版本

```bash
hexo generate
```

### 部署到 GitHub Pages

```bash
hexo deploy
```
